# SWキャッシュと持続キャンバスの鉄則（4〜6）

鉄則は全7項目の一連セット。1〜3と7は `.claude/rules/3d-placement.md` にある。

- 鉄則4. 新しいファイルを追加したら **sw.js の CACHE リストへの追加を忘れない**（sedの版数一括更新は既存行しか書き換えない）。
- 鉄則5. **持続キャンバスを追加したら、シーン再描画の掃除セレクタに除外を追加する**: app.js は再レンダリング時に `canvas:not(.sky-canvas):not(.sky-fx-canvas):not(.water-surface-canvas)` 以外のcanvasを削除する。除外し忘れると初回の再描画で静かに消える（空FXレイヤーで発生した）。
- 鉄則6. **版数を上げてからデータJSONを書き換えるとSWキャッシュが汚染される**: 版数アップ後に一度でもページを読み込むと（Stopフックの自動オープン含む）、SWインストール時点の内容が新しい `?v=` キーでキャッシュされ、その後のJSON再生成が届かない。対策として `.json` はSWでネットワーク優先にした（sw.js）— これをキャッシュ優先へ戻してはいけない。作業順も「内容の生成が終わってから版数を上げる」を守る。
