# monochrome-fracture-bloom

モノクローム、断片的な形、鋭い構成、静かな緊張感をイメージした植物用のモデルフォルダです。
具体的な作家名や絵画名はフォルダ名に使わず、アプリ内では独自の作品名を付けます。

## 入れる場所

- `stage-01-seed/`: 種
- `stage-02-sprout/`: 発芽
- `stage-03-leaves/`: 双葉、葉
- `stage-04-bud/`: 若苗、つぼみ前
- `stage-05-pre-bloom/`: つぼみ
- `stage-06-bloom/`: 開花
- `reference-images/`: 生成用の参考画像

GLBファイル名はTripoの書き出し名のままで大丈夫です。
