# Artarium 開発スケジュール案

最終更新: 2026-07-01

作業ペース前提: 1日あたり約3時間（1タスク＝1営業日で完了）。5営業日ごとに余白日を1日はさみ、遅れや差し込み作業を吸収する。作業36日＋余白7日＝全43営業日で、8月後半（2026-08-28）の完了を狙う。

## 更新ルール

開発順、日数、優先順位、完了状態が変わった場合は、この資料を更新する。
仕様として確定した内容は `docs/specification.md`、実装手順は `docs/development-instructions.md`、全体の機能一覧は `docs/roadmap.md` に反映する。

## 結論

最初にやるべきことは、3Dモデルとコレクション体験の完成度を上げること。

理由:

- Artarium の価値は「歩数機能」よりも「美術館のように植物作品を鑑賞できること」にある
- 3Dモデル、土台、水面、額縁の見え方が決まると、画面デザインも仕様も固めやすい
- スマホアプリ化は、Web版の体験が固まってから進めた方が作り直しが少ない

おすすめ順:

1. 植物モデルと土台の見え方を固める
2. 額縁とコレクション画面を整える
3. ユーザー名や作品詳細など、鑑賞体験を追加する
4. マネタイズ方針を決める
5. 歩数連携とスマホアプリ化の技術検証に進む

## Phase 1: 現状整理と制作ルール固定

目安: 1日

目的:
この先の追加作業で迷わないよう、モデル、画面、文言、保存設定のルールを固定する。

やること:

- 現在の植物一覧を確認する
- どの植物を初期リリース対象にするか決める
- モデルの命名ルールを確認する
- 土台タイプの使い分けを確認する
- 額縁タイプの数を決める
- 今後使わない機能を整理する

完了条件:

- 初期リリース対象の植物が決まっている
- モデル追加ルールが決まっている
- 作業順が決まっている

## Phase 2: 植物モデルと土台の調整

目安: 10日

目的:
初期10種類の植物がホーム画面できれいに見える状態を作る。

優先順位:

1. Sunflower Bloom
2. Water Lily Bloom
3. Aquatic Bloom
4. The Scream Bloom
5. Renaissance Smile Bloom
6. 追加植物 1
7. 追加植物 2
8. 追加植物 3
9. 追加植物 4
10. 追加植物 5

日数内訳:

| 作業 | 目安 |
| --- | ---: |
| 既存5種類の6ステージ調整 | 5日 |
| 追加5種類の候補決定とフォルダ準備 | 1日 |
| 追加5種類のモデル配置と読み込み | 2日 |
| 追加5種類の初期調整 | 1日 |
| 全体確認とズレ修正 | 1日 |

やること:

- 各ステージのGLBを読み込む
- 植物のサイズ、位置、角度を調整する
- 土台との接地感を合わせる
- 水面植物は反射を調整する
- デモ版で保存する
- 本番へ反映する
- 本番画面で確認する

完了条件:

- 初期10種類がStage1からStage6まで表示できる
- ホーム画面で植物が大きく美しく見える
- 土台と植物が自然につながっている
- 水面植物の反射が不自然ではない
- 植物ごとの設定が混ざっていない

## Phase 3: 額縁選択とコレクション体験の改善

目安: 5日

目的:
開花後に「作品になった」と感じられる流れを完成させる。

日数内訳:

| 作業 | 目安 |
| --- | ---: |
| 額縁GLBまたは額縁デザイン準備 | 1日 |
| 額縁選択画面の改善 | 1日 |
| 額縁内の植物サイズ調整 | 1日 |
| コレクション画面の展示改善 | 1日 |
| 全体確認と修正 | 1日 |

やること:

- 額縁候補を整理する
- 額縁GLBを入れるか、CSS額縁を磨くか決める
- 額縁選択画面で開花植物がきれいに見えるようにする
- 額縁から植物が飛び出しすぎないようにする
- コレクション画面で作品を大きく見せる
- 作品名と説明文のバランスを整える

完了条件:

- 60,000歩到達後、ホームに開花完了状態と「額装を選ぶ」導線が出る
- ユーザーが「額装を選ぶ」を押した後、額縁選択画面が出る
- 額縁選択画面で実際の植物が見える
- 額縁確定後、コレクションに表示される
- コレクション画面が美術館らしく見える

## Phase 4: UI/UXの高級感調整

目安: 4日

目的:
アプリ全体を「高級感のある小さな美術館」に近づける。

日数内訳:

| 作業 | 目安 |
| --- | ---: |
| ホーム画面の余白と文字サイズ調整 | 1日 |
| コレクション画面のデザイン調整 | 1日 |
| 設定画面の整理 | 0.5日 |
| フォント、色、ボタン調整 | 1日 |
| スマホ幅確認 | 0.5日 |

やること:

- ホームの文字主張を抑える
- 植物の表示領域を優先する
- ボタンを控えめにする
- 余計な説明や数値を減らす
- 黒、深茶、金、生成り、暗い青の印象に寄せる
- 画面崩れがないか確認する

完了条件:

- 安っぽく見えない
- 画面がごちゃついていない
- 植物が主役に見える
- スマホ画面幅で破綻していない

## まず今すぐやるなら

最初の作業は、Sunflower Bloom の6ステージ調整がおすすめ。

理由:

- すでに見た目の方向性が比較的分かりやすい
- 土の丘との組み合わせで基準を作りやすい
- 他の土植物の調整基準になる
- コレクションで見せた時に完成イメージを作りやすい

次に Water Lily Bloom を調整する。
水面、反射、水上植物の基準になるため。

この2つが固まると、土系と水面系の両方の基準ができる。

## 成長設定変更後の遊ばれ方

1作品の完成に必要な歩数:

- 60,000歩

10作品の完成に必要な歩数:

- 600,000歩

想定期間:

| 1日の歩数 | 1作品 | 10作品 |
| ---: | ---: | ---: |
| 4,000歩 | 約15日 | 約150日 |
| 6,000歩 | 約10日 | 約100日 |
| 8,000歩 | 約8日 | 約75日 |
| 10,000歩 | 約6日 | 約60日 |

この設定だと、初期10種類だけでも約2から5か月程度の継続余地がある。
日常的に歩く人には短すぎず、ライトユーザーには少し長めの設計になる。
