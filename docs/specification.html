Artarium 仕様書

最終更新: 2026-06-29

更新ルール

この仕様書は Artarium の現在仕様を記録する。 仕様変更があった場合は、実装と同時に該当項目を書き換える。 外部説明用の要約は docs/presentation.md、作業手順は docs/development-instructions.md に反映する。

アプリ名

Artarium - 名画の庭

概要

著作権フリーの名画や美術的モチーフをもとにした植物を、歩数で育てるスマホアプリ前提のWebプロトタイプ。 開花した植物は額縁を選んでコレクションに収蔵し、美術館の展示作品のように鑑賞する。

対象プラットフォーム

現在:

  • Webブラウザ
  • PWA対応
  • PCブラウザ上でもスマホ画面サイズで確認

将来:

  • iOSアプリ
  • Androidアプリ
  • Expo / React Native への移行を想定

対象ユーザー

主な対象:

  • 美術館やアート鑑賞が好きな人
  • 散歩や歩数習慣を楽しく続けたい人
  • 落ち着いた雰囲気の育成・収集アプリを求める人
  • 植物、花、インテリア、雑貨が好きな人
  • 派手なゲームUIや強い競争要素が苦手な人

想定年齢:

  • 20代後半から50代

利用動機:

  • 歩く理由を作りたい
  • 日々の歩数を美しい成果物に変換したい
  • 自分だけの作品コレクションを作りたい
  • 健康管理アプリより情緒的な体験で続けたい

重視する体験:

  • 毎日少しずつ進む
  • 開花した時に達成感がある
  • コレクションを眺める満足感がある
  • 課金しなくても基本体験が成立する

主要ファイル

  • index.html: 画面構造
  • styles.css: デザイン
  • app.js: ロジック、状態管理、3D表示
  • data/plants.json: 植物データ
  • models/: GLBモデル
  • vendor/: Three.js関連ファイル
  • sw.js: Service Worker
  • manifest.webmanifest: PWA設定

画面

ホーム

役割:

  • 現在育成中の植物を表示する
  • 植物を主役として見せる
  • 開花後は額縁選択へ進める

仕様:

  • 1度植物を選んだら、開花するまで他の植物は選べない
  • 余計な数値表示はホームに出しすぎない
  • デモモードでは3D調整パネルを併設する

コレクション

役割:

  • 額装済みの完成作品を鑑賞する

仕様:

  • Stage6 到達だけでは表示されない
  • 額縁を選び、確定した植物だけ表示する
  • 作品名と説明を表示する
  • 実在作家名は表示しない

設定

役割:

  • 歩数連携や開発用操作を置く

仕様:

  • 歩数同期
  • DeviceMotionによる簡易歩数検知
  • 開発用歩数加算
  • リセット
  • ユーザー名関連

額縁選択

役割:

  • 開花した植物をどの額縁に入れるか選ぶ

仕様:

  • 60,000歩到達による開花完了後に表示
  • 額縁候補を表示
  • プレビューには仮画像ではなく開花した植物モデルを表示
  • 背景選択は現在無効
  • 確定後、コレクションに収蔵

デモ版 3D調整

アクセス:

?demo=1

役割:

  • 植物モデルと土台モデルの見え方を調整する
  • デモ設定を本番へ反映する

調整項目:

  • 植物の種類
  • 成長ステージ
  • 土台タイプ
  • 植物サイズ
  • 植物X/Y/Z
  • 植物角度X/Y/Z
  • 土サイズ
  • 土X/Y/Z
  • 土角度X/Y/Z
  • 反射濃さ
  • 反射高さ
  • 反射奥行き
  • 反射潰れ具合
  • 反射サイズ

操作:

  • 保存
  • 本番へ反映
  • 本番で確認
  • 反射を自動調整
  • 初期値

成長仕様

歩数から成長ポイントを付与する。

  • 10歩 = 1成長ポイント
  • Stage1 から Stage6 まで成長
  • 1段階あたり約10,000歩を目安に進む
  • Stage6の表示には50,000歩で到達する
  • 60,000歩到達時に開花完了状態になる
  • 額縁選択とコレクション収蔵は、ユーザーが「額装を選ぶ」を押した後に行う

しきい値:

Stage成長ポイント歩数換算
Stage10pt0歩
Stage21,000pt10,000歩
Stage32,000pt20,000歩
Stage43,000pt30,000歩
Stage54,000pt40,000歩
Stage65,000pt50,000歩
開花完了6,000pt60,000歩

完成期間の目安:

  • 必要歩数: 60,000歩
  • 1日6,000歩の場合: 約10日
  • 1日8,000歩の場合: 約8日
  • 1日10,000歩の場合: 約6日
  • 10種類すべて完成する場合: 600,000歩
  • 10種類すべてを1日6,000歩で進める場合: 約100日

歩数連携

Web版で対応する入力:

  • window.Artarium.receiveStepData({ todaySteps, totalSteps })
  • window.ArtariumStepBridge.getTodaySteps()
  • DeviceMotionEvent による簡易歩数検知
  • 開発用テスト加算

スマホアプリ化後の想定:

  • iOS: HealthKit
  • Android: Health Connect

土台仕様

土台は植物ごとに紐づく。 ユーザーが本番画面で土台を選ぶ仕様ではない。

現在の土台:

soilType表示名モデル
gallery---loam土の丘models/shared/soil/soil+pile+3d+model+512.glb
water---surface水面models/shared/bases/water---surface/water+dish+3d+model+1k.glb

水面仕様

soilType が water-surface、または environmentType が water の植物は水面環境として扱う。

水面モデルには透明感、色味、粗さ、光沢の調整を加える。

反射:

  • 植物モデルをクローンする
  • Y方向に反転する
  • 水面の上に薄く重ねる
  • ステージが進むほど反射をやや強くする
  • デモ版では自動調整ボタンを使える

3D表示仕様

Three.js を使用する。

読み込み順:

  1. vendor/three.module.js
  2. vendor/GLTFLoader.js
  3. 失敗時はCDNを試す

モデルがない場合:

  • プレースホルダー表示
  • CSSベースのフォールバック

植物は自動回転しない。 ユーザー操作による回転も現在は無効。

デザイン仕様

方向性:

  • 高級感のある小さな美術館
  • 暗めの展示室
  • 黒とガラス感
  • 木目、石材、真鍮、金縁
  • 鑑賞アプリのように上品

色:

  • 黒
  • 深い茶色
  • 金
  • 生成り
  • 暗い青

UI:

  • ボタンはシンプルで控えめ
  • 情報量を抑える
  • 植物を中央の展示作品として見せる
  • ゲームっぽい派手な表現は避ける

文言仕様

実在作家名はコレクション画面などに表示しない。

作者欄は将来的に、アプリ開始時に入力したユーザー名を反映する方針。

作品名と説明は分かりやすくする。

例:

作品名: ひまわりの記憶
説明: 明るい黄色と筆あとをイメージした植物作品

マネタイズ仕様

基本方針:

  • 無料で開始できる
  • 歩いて育てる基本体験は無料で成立させる
  • 課金対象は主に植物、額縁、展示室、保存・同期などの拡張要素にする
  • 高級感のある鑑賞体験を壊す広告や強い課金誘導は避ける

初期リリース案:

区分内容
無料初期植物数種類、基本額縁、基本コレクション
有料植物パック追加植物、テーマ別植物セット、季節植物
有料額縁パック高級額縁、素材違い、展示室に合う額装
有料展示室テーマ壁、照明、床、台座などの鑑賞空間
広告なし買い切り広告を入れる場合の削除オプション
サブスクリプション毎月の新作植物、限定額縁、クラウド保存など

優先度:

  1. 追加植物パック
  2. 額縁・展示室カスタム課金
  3. 広告なし買い切り
  4. サブスクリプション

避ける課金:

  • 成長速度を直接買わせる課金
  • 毎日の歩数達成を阻害する課金
  • 作品鑑賞中に強く割り込む広告
  • ユーザーが育てた作品を人質にする保存制限

検討中:

  • 初期無料植物数
  • 追加植物パックの価格
  • 額縁パックの価格
  • 月額プランを導入するか
  • 広告を入れるかどうか

モデル推奨設定

Tripoなどで作成するGLBは軽量化を優先する。

目安:

  • 512から1Kテクスチャを基本にする
  • 植物は必要に応じて1K
  • ポリゴン数は20,000以下を目安にする
  • スマホ表示前提なので過剰な4Kや高ポリゴンは避ける
