Artarium 仕様書

最終更新: 2026-07-10

更新ルール

この仕様書は Artarium の現在仕様を記録する。 仕様変更があった場合は、実装と同時に該当項目を書き換える。 外部説明用の要約は presentation.md、作業手順は development-instructions.md に反映する。 要件・設計・UI/UXの監査記録（日付つきスナップショット）は requirements.md / architecture.md / ux-review.md を参照する。

アプリ名

Artarium - 名画の庭

概要

著作権フリーの名画や美術的モチーフをもとにした植物を、歩数で育てるスマホアプリ前提のWebプロトタイプ。 開花した植物は額縁を選んでコレクションに収蔵し、美術館の展示作品のように鑑賞する。

対象プラットフォーム

現在:

  • Webブラウザ
  • PWA対応
  • PCブラウザ上でもスマホ画面サイズで確認

将来:

  • iOSアプリ
  • Androidアプリ
  • Expo / React Native への移行を想定

対象ユーザー

主な対象:

  • 美術館やアート鑑賞が好きな人
  • 散歩や歩数習慣を楽しく続けたい人
  • 落ち着いた雰囲気の育成・収集アプリを求める人
  • 植物、花、インテリア、雑貨が好きな人
  • 派手なゲームUIや強い競争要素が苦手な人

想定年齢:

  • 20代後半から50代

利用動機:

  • 歩く理由を作りたい
  • 日々の歩数を美しい成果物に変換したい
  • 自分だけの作品コレクションを作りたい
  • 健康管理アプリより情緒的な体験で続けたい

重視する体験:

  • 毎日少しずつ進む
  • 開花した時に達成感がある
  • コレクションを眺める満足感がある
  • 課金しなくても基本体験が成立する

主要ファイル

  • index.html: 画面構造
  • styles.css: デザイン
  • app.js: ロジック、状態管理、3D表示
  • sky-background.js / water-surface.js / plant-effects.js / weather.js / ambient-sound.js: 空・水面・植物演出・天気・環境音の各モジュール
  • data/plants.json: 植物データ
  • data/model-settings.json: 3D配置の焼き込み値（配置調整の正）
  • models/: GLBモデル
  • vendor/: Three.js関連ファイル
  • sw.js: Service Worker
  • manifest.webmanifest: PWA設定

画面

画面共通の操作感（2026-07-21 apple-designスキル適用）:

  • 押下フィードバック: タブ・種カード・コレクションの額・額縁選択・閉じるボタンは、押した瞬間（離した時ではなく）にわずかに沈み、戻りはひと呼吸ゆっくり
  • タブ切替は短いフェード（200ms）で繋ぐ（瞬間切替をやめる）
  • モーダル表示中は背景操作と背景スクロールを止め、Tabキーはモーダル内を循環する。閉じると開く前の操作位置へ戻る（2026-07-22）
  • すべてのモーダル（作品詳細・額縁選択・週間振り返り・名前入力）は下からわずかに浮かんで現れ、閉じるときは同じ道を戻る（2026-07-24 展開。reduced-motion時はフェードのみ）
  • prefers-reduced-transparency ではすりガラス（backdrop-filter）をやめて面をほぼ不透明に、prefers-contrast: more では操作要素にレイアウトを崩さない内側輪郭を足す（2026-07-24 apple-designスキル §14）
  • スクロールエッジ: スクロールするビュー（コレクション・設定）の下端は、浮いているタブバーへ柔らかい暗がりで溶ける（境界線でなくフェード。没入型のホームには掛けない。2026-07-24 §12）
  • すりガラスの厚み階層: 全画面の幕=18px、パネル=12px、チップ・小ボタン=8pxの3層に統一。シーン上の淡い文字（進捗ヒント等）はコントラストを一段上げる（2026-07-24 §12）

ホーム

役割:

  • 現在育成中の植物を表示する
  • 植物を主役として見せる
  • 開花後は額縁選択へ進める

仕様:

  • 1度植物を選んだら、開花するまで他の植物は選べない
  • 種候補を押した確認画面では、開花後ではなく Stage1 の種モデルを、土・水面を見せない標本展示として表示する。植物エフェクト（浮遊 bob 等）は付けない — 標本演出と位置を取り合い、水面植物の種が震える不具合になるため（2026-07-14 修正）
  • Stage1 の種は直立させず、種ごとに個別の傾き（plantRotZ）で植え穴に自然に横たえる。土植物は半ば埋もれ、水面植物は水面に触れて浮かぶ高さに合わせる。傾きの向きは種ごとに変えて有機的にする（2026-07-23 ユーザー決定。直立ルールの例外は Stage1 のみ）
  • 「この種を育てる」で種が縮小・下降し、暗転を挿んで通常の土台の育成画面へ移る
  • 額装・収蔵後は「次の作品を選ぶ」から未収蔵の植物を選べる
  • 余計な数値表示はホームに出しすぎない
  • 天気の一言（雨・雪などの挨拶）は画面上部・ヘッダーの下に表示する（植物と重ねない。2026-07-14 位置変更）
  • 進捗ライン（タブバー直上）には初回一度だけ「タップで歩数を同期できる」旨の小さなヒントを出す（2026-07-14 追加）
  • デモモードでは3D調整パネルを併設する

コレクション

役割:

  • 額装済みの完成作品を鑑賞する

仕様:

  • Stage6 到達だけでは表示されない
  • 額縁を選び、確定した植物だけ表示する
  • 額装確定後はコレクション上部へ移動し、新しい作品の照明が点く収蔵演出を表示する
  • 作品名と説明を表示する
  • 作者名と収蔵日を、美術館の収蔵票を意識した形式でプレートに表示する
  • 実在作家名は表示しない
  • 額装名のラベル（「額装: 〜」）は表示しない（額縁は見た目そのもので語る。2026-07-14 ユーザー決定）
  • 全体の作品数（全何種か）は表示しない（2026-07-10 ユーザー決定。「作品 3点」のように収蔵済みの数だけ示す）
  • 作品詳細モーダルは下からわずかに浮かんで現れ、閉じるときは同じ道を戻る（入りと出の対称。reduced-motion時はフェードのみ。2026-07-21 apple-designスキル適用）
  • 作品のドラッグ回転は「手で扱う」感触（2026-07-24 apple-designスキル §5/§6/§9）: 指を離した速度を引き継いで回り続け滑らかに減速、端（±0.38）は硬い壁でなく粘る抵抗＋離すとバネで戻る、慣性中に掴むとその場で止まって追従（reduced-motion時は慣性なし）

設定

役割:

  • 歩数連携や開発用操作を置く

仕様:

  • 設定項目は「歩数」「演出と音」「記録」「データ」の4グループに近接でまとめる（関連するものを近くに・危険な操作(初期化)は接続状態と共にデータ群へ隔離。2026-07-24 apple-designスキル §16）
  • 歩数同期
  • DeviceMotionによる簡易歩数検知
  • 開発用歩数加算（デモモードのみ表示）
  • リセット
  • 作者名の表示と変更（タップで名前入力モーダルを開く。2026-07-10）
  • 環境音のオン/オフ
  • 植物のエフェクト（ゆれ・粒子・花びら）のオン/オフ（2026-07-10 追加。オフ時はエフェクトを生成しない）
  • 週間振り返りの表示
  • 接続状態（オンライン／オフラインと端末保存状態）の表示

週間振り返り

役割:

  • 直近7日の歩数と成長を振り返る

仕様:

  • 直近7日の歩数を棒グラフで表示
  • 合計歩数と植物の成長コメントを表示
  • 日曜18時以降に週1回自動表示（週キーで表示済み管理）
  • 設定画面から手動でも開ける

鑑賞モード

役割:

  • UIを消して空と植物だけを全画面で眺める

仕様:

  • ホームの「眺める」ボタンで開始
  • Escまたはタップで解除
  • 表示中は背景スクロールをロック
  • 表示中はカメラが約14秒周期でごくゆっくり寄り引きする「呼吸」が入る（prefers-reduced-motion 時は無効。2026-07-14 追加）

図鑑「名画の由来」

役割:

  • 収蔵した作品のモチーフとなった名画の解説を読む

仕様:

  • コレクション画面の下部に表示
  • 収蔵済みの作品の数だけ解説が増える
  • 解説データは app.js の CODEX_NOTES で管理

額縁選択

役割:

  • 開花した植物をどの額縁に入れるか選ぶ

仕様:

  • 60,000歩到達による開花完了後に表示
  • 額縁候補は「額の角の見本」スウォッチ＋日本語名で表示し、選択中の額縁には「素材の物語」の一文を添える（2026-07-10）
  • 額は7種（2026-07-14 拡充）: 胡桃の深箱・美術館の黒・浮かぶ楓・金箔の額・白の画廊・古銀の額・黒檀と金。すべて手続き生成（GLB不使用）で、仕上げ別の材質（木目・漆・金箔・銀箔・石膏白・黒檀）を持つ。美術館の黒は金縁・マットの無い純黒ミニマル（黒檀と金との役割分担。2026-07-14）
  • 全植物ですべての額から選べる（getFrameOptions は FRAME_TYPES 全キーを返す。plants.json の frameOptions は旧3種の記載のため参照しない）
  • 額の品質: 段のあるプロファイル（外縁の立ち上がり）・マット紙の面取り線・仕上げ別の内縁色（金箔=古金の影色、古銀=銀、黒檀=太い金）を備える（2026-07-14）
  • プレビューには開花した植物モデルと、収蔵後の姿を先に見せる真鍮プレート（作品名・作者名）を表示
  • 背景選択は現在無効
  • 確定時は「収蔵の儀式」演出（照明が落ち、金の光が額縁をなぞる約2秒。reduced-motion時は省略）を経てコレクションに収蔵
  • 額の中は「描かれた絵」として見せる（2026-07-14）: 土植物は額装シーンに3Dの土を置かず、パレット塗りの背景に「描かれた大地」（土色の帯＋固定配置の筆あと）と足元の淡い影を焼き込んで受ける。水面植物は水盤が作品の一部のため従来どおり

デモ版 3D調整

アクセス:

?demo=1

役割:

  • 植物モデルと土台モデルの見え方を調整する
  • デモ設定を本番へ反映する

調整項目:

  • 植物の種類
  • 成長ステージ
  • 土台タイプ
  • 植物サイズ
  • 植物X/Y/Z
  • 植物角度X/Y/Z
  • 土サイズ
  • 土X/Y/Z
  • 土角度X/Y/Z
  • 影 濃さ / 影 長さ / 影 奥行き（土植物の接地影。＋で手前・−で奥。2026-07-24 追加）
  • 反射濃さ
  • 反射高さ
  • 反射奥行き
  • 反射潰れ具合
  • 反射サイズ

操作:

  • 保存（スライダーで動かした値は「調整オーバーライド」として別枠にも記録され、再読み込み後も焼き込み値より優先して維持される。2026-07-23 追加 — それ以前は起動時の焼き込み優先で保存が巻き戻っていた）
  • 本番へ反映
  • 本番で確認
  • 調整値を書き出す（全植物×全ステージの焼き込み対象キーをJSONでダウンロード。手動調整の結果をスクショや転記なしで焼き込みに受け渡すための機能。2026-07-23 追加）
  • 反射を自動調整
  • 初期値（押すと確認ダイアログを出し、OKで焼き込み値（model-settings.json）へ即時に戻す。そのステージの調整オーバーライドも消去。2026-07-23 — 旧実装は基準植物の現在値を写すだけで、水面植物では実質何もしていなかった）
  • 連続成長プレビュー（ステージ内の育ち具合 0〜100% を確認するスライダー。2026-07-13）

デモ版はパネルをスクロールしても植物が見えたまま調整できる（PC幅はシーンを上部固定、スマホ幅はシーン下部が貼り付く。2026-07-13）。

成長仕様

歩数から成長ポイントを付与する。

  • 10歩 = 1成長ポイント
  • Stage1 から Stage6 まで成長
  • 連続成長（2026-07-13）: 同じステージ内でも、進捗に応じて植物が 86%→100% のサイズへ滑らかに育つ（根元は土に固定）。毎日開くたびに昨日より少し大きい姿になる。デモモードは配置調整の検証を妨げないため対象外
  • ステージ連動カメラ（2026-07-13）: ホームのシーンはステージが進むほどカメラがゆっくり引いていく（Stage1=寄り→Stage4以降=定位置）。小さな芽は近くで、育った姿は全体を眺める構図になる
  • 1段階あたり約10,000歩を目安に進む
  • Stage6の表示には50,000歩で到達する
  • 60,000歩到達時に開花完了状態になる
  • 額縁選択とコレクション収蔵は、ユーザーが「額装を選ぶ」を押した後に行う

歩数連携

Web版で対応する入力:

  • window.Artarium.receiveStepData({ todaySteps, totalSteps })
  • window.ArtariumStepBridge.getTodaySteps()
  • DeviceMotionEvent による簡易歩数検知
  • 開発用テスト加算（デモモードのみ）

同期の導線（2026-07-10）:

  • 起動時にブリッジがあれば自動同期する
  • 一度開始した簡易歩数計は、次回起動時に自動で再開する（iOSは権限が必要なため最初のタップで再開）
  • ホームの進捗ライン（タブバー直上）をタップすると、同期と歩数計開始をその場で行える
  • 歩数まわりの操作は「ホームの進捗ライン」と「設定」の2箇所に集約する（旧 grow-view は廃止）

スマホアプリ化後の想定:

  • iOS: HealthKit
  • Android: Health Connect

PWAインストール誘導

  • 初回の額装（コレクション収蔵）の約2.6秒後に、一度だけ「ホーム画面に追加」を控えめに提案する
  • 「あとで」を選ぶか一度提案したら、以後は表示しない（artarium-install-hinted）
  • beforeinstallprompt が使えるブラウザ（Android Chrome等）のみ。スタンドアロン起動中は出さない

環境演出

空・天気・季節

  • 空はWebGL2シェーダーで描画し、時刻（8ポイントの色補間）・季節・実天気に連動する
  • 天気は Open-Meteo API から取得する（現在地、位置情報拒否時は東京、30分キャッシュ）
  • 取得失敗・オフライン時は時刻連動のみで動作する
  • WebGL2非対応時はCSS背景にフォールバックする
  • 地平線には対岸の丘なみのシルエットと霞を描く（2026-07-13 追加）。霧が濃いほど対岸は霞に溶ける
  • 夜は対岸の麓に遠い家々の灯りがまばらにともり、水際に映り込む（星の出る暗さでゆっくりまたたく。2026-07-13 追加）
  • 朝（7時前後）と夕方（17時半前後）には、渡り鳥の群れがときどき空を渡る（FXレイヤー。雨天は飛ばない。2026-07-13 追加）
  • 夜の月は今日の実際の月齢の形で昇る（2000-01-06の新月基準の概算。球面陰影で欠け際を描き、影側は地球照でかすかに見える。デバッグは setSkyMoonPhaseOverride。2026-07-13 追加）
  • 雨が止んで空が明るくなると、数分だけうっすら虹が架かる（setSkyWeather で雨→晴れの遷移を検知。夜・降雨中は出ない。2026-07-13 追加）
  • 雨は奥行きの違う3層の細い筋で描き、雨量で降り方の性格が変わる（小雨=まばらな針のような点描がほぼ垂直にゆっくり、本降り=長い筋が風に強く流されて速く、地平線が雨の靄で煙る。夜はほとんど見えない明るさまで落とす。列ごとに落下位相をずらして格子縞を防ぐ。2026-07-13 刷新）。雪は2層の丸い粒が左右に揺れながらふわりと落ちる（2026-07-13 刷新）

水面

  • 波動方程式シミュレーションによるリアルタイム水面
  • タップで波紋、雨天時は雨滴が発生する
  • float texture 非対応時はCSS水面にフォールバックする
  • 水の不透明度は全植物0.5（2026-07-23 ユーザー決定）。水中に沈む植物の胴体は水を透かしてうっすら見える（喫水線クリップは2026-07-24に一度導入したがユーザー判断で取りやめ）

土の丘

  • 土植物の土台はコード生成（2026-07-13 採用。GLB soil+pile は不使用に）。低く広い花壇型で、うねり・土くれ・細粒の3スケールの起伏＋擬似AO（下限は稜線が空の光を拾う明るさ）＋粒のむら＋植え穴と掘り縁＋熊手目（植物のまわりの同心円の手入れ跡）＋汀（水際の濡れた暗い裾）＋半分埋まった小石＋裾に小さな草の株
  • 植物は足元に接地影を落とす（デカール方式。2026-07-24 ユーザー要望）: 植物を真上から見た黒いシルエットを一度テクスチャに描き、土の山の表面に貼り付ける。土の起伏に密着するので埋まらず、土は常に植物より奥のため本体に被らない。貼り付け位置は本体の真下でなく手前の斜面へ半歩ずらし、午後の日差しの影のように見せる。濃さはステージで成長し、デモパネルの「影 濃さ」「影 長さ」で調整可。シーンを描く時点の太陽・天気に連動する（2026-07-24）: 左右の向きは太陽と反対側へ、長さは太陽が低いほど長く、濃さは太陽が高いほど濃く・曇り雨は淡く・夜は月明かりの淡い影。開いたままの画面内でリアルタイムには動かず、シーンの描き直し時（起動・画面切替）に更新される。シャドウマッピング（実影）と斜面に寝かせるシルエットも試したが、前者はカメラが地面すれすれで影がほぼ映らず、後者は起伏に埋まる/本体に被るため不採用
  • Stage1 では種のまわりに掘り返した土くれを添えて「植えた」状態を作る。接触影の平面ディスクは置かない — 土に沈む種の手前に重なり、種が影を貫通して見えるため（植え穴の頂点AOを深さ比例の滑らかな陰にし、穴の半径も種に合わせて絞った。2026-07-23）
  • 乱数を使わない決定的生成（毎回同じ丘。配置検証の再現性を保つ）
  • 土は従来どおり植物のパレット色に染まる（prepareSoilModel）。草の株は染めから除外
  • 雨の日は土が湿って暗くなる（雨量に応じて材質を減光。2026-07-13 追加）
  • 水面植物の器（water-surface）は従来どおりGLB

植物エフェクト

  • 植物ごとにモチーフに合わせた揺れ・粒子・開花後の散りを定義する
  • 散る花びらの色は開花モデルの実テクスチャから採取する
  • 水面植物の浮き沈み（bob）は基準±0.035に対し、Stage2以降は約35%（±0.012）、Stage1（種）は約1/3（±0.011）に抑える — 種は水面から出たり沈んだりして見え、成木も揺れが大きすぎたため（2026-07-23 ユーザー指示）

環境音

  • Web Audio によるリアルタイム合成。音声ファイルは使わない
  • 雨・波紋・雷鳴に加え、時刻の音風景（2026-07-13 追加）:
  • 朝（5〜9時）: 小鳥のさえずり（強い雨の朝は鳴かない）
  • 夜（19〜4時）: 虫の音（強い雨の夜は静まる）
  • 風: 天候に連動（植物の揺れと同じ強さ。快晴の凪は無音）
  • 渡り鳥: 群れが空を渡っている間だけ、遠くでかすかに鳴き交わす（空FXレイヤーから setSkyFlockListener 経由で通知。2026-07-13 追加）
  • 設定画面でオン/オフを切り替え、localStorage に保存する

点灯式（開花演出）

ステージ上昇・開花完了時の演出。

  1. 暗転（約0.45秒）で場内が静まる
  2. スポットライトが点灯する（光の中心は花頭の位置に合わせる）
  3. 約4秒で平常の明るさへ戻り、ベールが消える
  4. 演出が完全に終わったあと（約5.2秒）に完成プレートが現れる（2026-07-10 変更。演出中はプレートを出さない）

prefers-reduced-motion 設定時は遷移を省略する。

土台仕様

土台は植物ごとに紐づく。 ユーザーが本番画面で土台を選ぶ仕様ではない。

現在の土台:

soilType表示名モデル

water-surface水面models/shared/bases/water-surface/water+dish+3d+model+1k.glb

水面仕様

soilType が water-surface、または environmentType が water の植物は水面環境として扱う。

水面モデルには透明感、色味、粗さ、光沢の調整を加える。

反射:

  • 植物モデルをクローンする
  • Y方向に反転する
  • 水面の上に薄く重ねる
  • ステージが進むほど反射をやや強くする
  • デモ版では自動調整ボタンを使える

3D表示仕様

Three.js を使用する。

読み込み順:

  1. vendor/three.module.js
  2. vendor/GLTFLoader.js
  3. 失敗時はCDNを試す

モデルがない場合:

  • プレースホルダー表示
  • CSSベースのフォールバック

植物は自動回転しない。 ユーザー操作による回転も現在は無効。

マネタイズ仕様

  • 無料で開始できる
  • 歩いて育てる基本体験は無料で成立させる
  • 課金対象は主に植物、額縁、展示室、保存・同期などの拡張要素にする
  • 高級感のある鑑賞体験を壊す広告や強い課金誘導は避ける

区分内容
