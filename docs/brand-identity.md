## ロゴ「The Living Frame」

構成要素の意味:

- **額縁 = 美術館の約束**: 歩みは「記録」ではなく「作品」として飾られる。金は旧アイコンの額縁色を継承。
- **芽 = 万歳する人（隠し要素）**: 茎と2枚の葉は、両手を上げて達成を喜ぶ人のシルエットに重なる。育つのは植物であり、歩いたユーザー自身。
- **水面 = Artariumの舞台**: 水面線と短い反射が、シャドーボックスの水面と「コレクションに残る記憶」を表す。
- **非対称の葉**: 左右の葉は高さ・大きさを揃えず、生きた植物の自然さを残す。

## 使用ルール

してよいこと:

- アイソレーション: シンボルの葉1枚分を最小余白とする
- 最小サイズ: フルカラー版24px、小サイズ形状16px
- 指定6色以内での配色バリエーション（緑地×金、金地×墨 など）
- 開花演出でのみブルーム・レッドを差す

してはいけないこと:

- 額縁の中に芽以外の要素を入れる（額縁は聖域）
- 回転・変形・グラデーション・ドロップシャドウの追加
- 葉のみ・額縁のみの単独使用（商標運用ルール）
- 蛍光色や彩度の高い緑への置き換え

## 検証記録（要約）

- **ストレステスト**: 16px・ダーク背景・単色印刷・金属刻印・刺繍・遠距離看板の6環境で検証。16px以下は小サイズ形状へ切り替えることで全環境合格。
- **グローバルテスト**: “artarium” は terrarium / planetarium の類推で直感的に読める。縦長フレームが鳥居・扉に誤読されないよう水面線を額縁内側に留め、開口比を名画の4:5に設定。緑+金は主要市場でポジティブ。
- **商標**: 「額縁×発芽×水面」の3要素同時使用は調査した主要ブランドと非類似。ただし出願前に弁理士による正式調査が必須。
- **スコア（v2最終）**: 記憶性 9.5 / 独自性 9.7 / 拡張性 9.6 / 汎用性 9.5 / プレミアム感 9.6
