# Artarium 仕様書

最終更新: 2026-07-10

## 更新ルール

この仕様書は Artarium の現在仕様を記録する。
仕様変更があった場合は、実装と同時に該当項目を書き換える。
外部説明用の要約は `presentation.md`、作業手順は `development-instructions.md` に反映する。
要件・設計・UI/UXの監査記録（日付つきスナップショット）は `requirements.md` / `architecture.md` / `ux-review.md` を参照する。

## アプリ名

Artarium - 名画の庭

## 概要

著作権フリーの名画や美術的モチーフをもとにした植物を、歩数で育てるスマホアプリ前提のWebプロトタイプ。
開花した植物は額縁を選んでコレクションに収蔵し、美術館の展示作品のように鑑賞する。

## 対象プラットフォーム

現在:

- Webブラウザ
- PWA対応
- PCブラウザ上でもスマホ画面サイズで確認

将来:

- iOSアプリ
- Androidアプリ
- Expo / React Native への移行を想定

## 対象ユーザー

主な対象:

- 美術館やアート鑑賞が好きな人
- 散歩や歩数習慣を楽しく続けたい人
- 落ち着いた雰囲気の育成・収集アプリを求める人
- 植物、花、インテリア、雑貨が好きな人
- 派手なゲームUIや強い競争要素が苦手な人

想定年齢:

- 20代後半から50代

利用動機:

- 歩く理由を作りたい
- 日々の歩数を美しい成果物に変換したい
- 自分だけの作品コレクションを作りたい
- 健康管理アプリより情緒的な体験で続けたい

重視する体験:

- 毎日少しずつ進む
- 開花した時に達成感がある
- コレクションを眺める満足感がある
- 課金しなくても基本体験が成立する

## 画面

### ホーム

役割:

- 現在育成中の植物を表示する
- 植物を主役として見せる
- 開花後は額縁選択へ進める

仕様:

- 1度植物を選んだら、開花するまで他の植物は選べない
- 種候補を押した確認画面では、開花後ではなく Stage1 の種モデルを、土・水面を見せない標本展示として表示する
- 「この種を育てる」で種が縮小・下降し、暗転を挿んで通常の土台の育成画面へ移る
- 額装・収蔵後は「次の作品を選ぶ」から未収蔵の植物を選べる
- 余計な数値表示はホームに出しすぎない
- デモモードでは3D調整パネルを併設する

### コレクション

役割:

- 額装済みの完成作品を鑑賞する

仕様:

- Stage6 到達だけでは表示されない
- 額縁を選び、確定した植物だけ表示する
- 額装確定後はコレクション上部へ移動し、新しい作品の照明が点く収蔵演出を表示する
- 作品名と説明を表示する
- 作者名と収蔵日を、美術館の収蔵票を意識した形式でプレートに表示する
- 実在作家名は表示しない
- 全体の作品数（全何種か）は表示しない（2026-07-10 ユーザー決定。「作品 3点」のように収蔵済みの数だけ示す）

### 設定

役割:

- 歩数連携や開発用操作を置く

仕様:

- 歩数同期
- DeviceMotionによる簡易歩数検知
- 開発用歩数加算（デモモードのみ表示）
- リセット
- 作者名の表示と変更（タップで名前入力モーダルを開く。2026-07-10）
- 環境音のオン/オフ
- 植物のエフェクト（ゆれ・粒子・花びら）のオン/オフ（2026-07-10 追加。オフ時はエフェクトを生成しない）
- 週間振り返りの表示

### 週間振り返り

役割:

- 直近7日の歩数と成長を振り返る

仕様:

- 直近7日の歩数を棒グラフで表示
- 合計歩数と植物の成長コメントを表示
- 日曜18時以降に週1回自動表示（週キーで表示済み管理）
- 設定画面から手動でも開ける

### 鑑賞モード

役割:

- UIを消して空と植物だけを全画面で眺める

仕様:

- ホームの「眺める」ボタンで開始
- Escまたはタップで解除
- 表示中は背景スクロールをロック

### 図鑑「名画の由来」

役割:

- 収蔵した作品のモチーフとなった名画の解説を読む

仕様:

- コレクション画面の下部に表示
- 収蔵済みの作品の数だけ解説が増える
- 解説データは `app.js` の `CODEX_NOTES` で管理

### 額縁選択

役割:

- 開花した植物をどの額縁に入れるか選ぶ

仕様:

- 60,000歩到達による開花完了後に表示
- 額縁候補は「額の角の見本」スウォッチ＋日本語名で表示し、選択中の額縁には「素材の物語」の一文を添える（2026-07-10）
- プレビューには開花した植物モデルと、収蔵後の姿を先に見せる真鍮プレート（作品名・作者名）を表示
- 背景選択は現在無効
- 確定時は「収蔵の儀式」演出（照明が落ち、金の光が額縁をなぞる約2秒。reduced-motion時は省略）を経てコレクションに収蔵

### デモ版 3D調整

アクセス:

```text
?demo=1
```

役割:

- 植物モデルと土台モデルの見え方を調整する
- デモ設定を本番へ反映する

調整項目:

- 植物の種類
- 成長ステージ
- 土台タイプ
- 植物サイズ
- 植物X/Y/Z
- 植物角度X/Y/Z
- 土サイズ
- 土X/Y/Z
- 土角度X/Y/Z
- 反射濃さ
- 反射高さ
- 反射奥行き
- 反射潰れ具合
- 反射サイズ

操作:

- 保存
- 本番へ反映
- 本番で確認
- 反射を自動調整
- 初期値

## 成長仕様

歩数から成長ポイントを付与する。

- 10歩 = 1成長ポイント
- Stage1 から Stage6 まで成長
- 1段階あたり約10,000歩を目安に進む
- Stage6の表示には50,000歩で到達する
- 60,000歩到達時に開花完了状態になる
- 額縁選択とコレクション収蔵は、ユーザーが「額装を選ぶ」を押した後に行う

しきい値:

| Stage | 成長ポイント | 歩数換算 |
| --- | ---: | ---: |
| Stage1 | 0pt | 0歩 |
| Stage2 | 1,000pt | 10,000歩 |
| Stage3 | 2,000pt | 20,000歩 |
| Stage4 | 3,000pt | 30,000歩 |
| Stage5 | 4,000pt | 40,000歩 |
| Stage6 | 5,000pt | 50,000歩 |
| 開花完了 | 6,000pt | 60,000歩 |

完成期間の目安:

- 必要歩数: 60,000歩
- 1日6,000歩の場合: 約10日
- 1日8,000歩の場合: 約8日
- 1日10,000歩の場合: 約6日
- 10種類すべて完成する場合: 600,000歩
- 10種類すべてを1日6,000歩で進める場合: 約100日

## 歩数連携

Web版で対応する入力:

- `window.Artarium.receiveStepData({ todaySteps, totalSteps })`
- `window.ArtariumStepBridge.getTodaySteps()`
- `DeviceMotionEvent` による簡易歩数検知
- 開発用テスト加算（デモモードのみ）

同期の導線（2026-07-10）:

- 起動時にブリッジがあれば自動同期する
- 一度開始した簡易歩数計は、次回起動時に自動で再開する（iOSは権限が必要なため最初のタップで再開）
- ホームの進捗ライン（タブバー直上）をタップすると、同期と歩数計開始をその場で行える
- 歩数まわりの操作は「ホームの進捗ライン」と「設定」の2箇所に集約する（旧 grow-view は廃止）

スマホアプリ化後の想定:

- iOS: HealthKit
- Android: Health Connect

## PWAインストール誘導

- 初回の額装（コレクション収蔵）の約2.6秒後に、一度だけ「ホーム画面に追加」を控えめに提案する
- 「あとで」を選ぶか一度提案したら、以後は表示しない（`artarium-install-hinted`）
- `beforeinstallprompt` が使えるブラウザ（Android Chrome等）のみ。スタンドアロン起動中は出さない

## 環境演出

### 空・天気・季節

- 空はWebGL2シェーダーで描画し、時刻（8ポイントの色補間）・季節・実天気に連動する
- 天気は Open-Meteo API から取得する（現在地、位置情報拒否時は東京、30分キャッシュ）
- 取得失敗・オフライン時は時刻連動のみで動作する
- WebGL2非対応時はCSS背景にフォールバックする

### 水面

- 波動方程式シミュレーションによるリアルタイム水面
- タップで波紋、雨天時は雨滴が発生する
- float texture 非対応時はCSS水面にフォールバックする

### 植物エフェクト

- 植物ごとにモチーフに合わせた揺れ・粒子・開花後の散りを定義する
- 散る花びらの色は開花モデルの実テクスチャから採取する

### 環境音

- Web Audio によるリアルタイム合成（雨・波紋・雷鳴）。音声ファイルは使わない
- 設定画面でオン/オフを切り替え、`localStorage` に保存する

### 点灯式（開花演出）

ステージ上昇・開花完了時の演出。

1. 暗転（約0.45秒）で場内が静まる
2. スポットライトが点灯する（光の中心は花頭の位置に合わせる）
3. 約4秒で平常の明るさへ戻り、ベールが消える
4. **演出が完全に終わったあと**（約5.2秒）に完成プレートが現れる（2026-07-10 変更。演出中はプレートを出さない）

`prefers-reduced-motion` 設定時は遷移を省略する。

## 土台仕様

土台は植物ごとに紐づく。
ユーザーが本番画面で土台を選ぶ仕様ではない。

現在の土台:

| soilType | 表示名 | モデル |
| --- | --- | --- |
| `gallery-loam` | 土の丘 | `models/shared/soil/soil+pile+3d+model+512.glb` |
| `water-surface` | 水面 | `models/shared/bases/water-surface/water+dish+3d+model+1k.glb` |

## 水面仕様

`soilType` が `water-surface`、または `environmentType` が `water` の植物は水面環境として扱う。

水面モデルには透明感、色味、粗さ、光沢の調整を加える。

反射:

- 植物モデルをクローンする
- Y方向に反転する
- 水面の上に薄く重ねる
- ステージが進むほど反射をやや強くする
- デモ版では自動調整ボタンを使える

## 3D表示仕様

Three.js を使用する。

読み込み順:

1. `vendor/three.module.js`
2. `vendor/GLTFLoader.js`
3. 失敗時はCDNを試す

モデルがない場合:

- プレースホルダー表示
- CSSベースのフォールバック

植物は自動回転しない。
ユーザー操作による回転も現在は無効。

## 額縁仕様

現在の額縁タイプ:

| frameType | 日本語名 | 英語名 | 素材の物語 |
| --- | --- | --- | --- |
| `walnut` | 胡桃の深箱 | Walnut Shadow Box | 深く艶めく木目が、花をしずかに抱く。 |
| `museum-black` | 美術館の黒 | Museum Black | 光を呑む漆黒が、色彩だけを浮かび上がらせる。 |
| `floating-maple` | 浮かぶ楓 | Floating Maple | 額と作品のあいだに光の隙間。花が宙に浮いて見える。 |

GLB配置状況（2026-07-10時点）:

- `museum-black`: 配置済み（`models/frames/museum-black/`）
- `walnut` / `floating-maple`: 未配置。CSSの額縁フォールバックで表示

GLB未配置の額は、手続き生成の3D箱額で表示する（2026-07-10 品質改善）:

- 額縁は手続き生成の木目テクスチャ（横木は横目・縦木は縦目）。`museum-black` のみ艶のあるラッカー仕上げ
- 開口の内側に金のフィレット、その奥にマット紙（アイボリーの台紙）。`floating-maple` は「光の隙間」が個性のためマット紙なし
- 箱の内壁は暗色に沈める（立体感を抑え、絵画として見せる。2026-07-10 ユーザー決定）
- 背板には植物のパレット4色から生成した「絵の具の背景」を描く（作品ごとに異なる。配置固定・カンヴァス質感・周辺減光つき）

Three.js自体が使えない場合はCSSの額縁フォールバックを使う（こちらにもマット紙表現あり）。

## 文言仕様

## マネタイズ仕様

基本方針:

- 無料で開始できる
- 歩いて育てる基本体験は無料で成立させる
- 課金対象は主に植物、額縁、展示室、保存・同期などの拡張要素にする
- 高級感のある鑑賞体験を壊す広告や強い課金誘導は避ける

初期リリース案:

| 区分 | 内容 |
| --- | --- |
| 無料 | 初期植物数種類、基本額縁、基本コレクション |
| 有料植物パック | 追加植物、テーマ別植物セット、季節植物 |
| 有料額縁パック | 高級額縁、素材違い、展示室に合う額装 |
| 有料展示室テーマ | 壁、照明、床、台座などの鑑賞空間 |
| 広告なし買い切り | 広告を入れる場合の削除オプション |
| サブスクリプション | 毎月の新作植物、限定額縁、クラウド保存など |

優先度:

1. 追加植物パック
2. 額縁・展示室カスタム課金
3. 広告なし買い切り
4. サブスクリプション

避ける課金:

- 成長速度を直接買わせる課金
- 毎日の歩数達成を阻害する課金
- 作品鑑賞中に強く割り込む広告
- ユーザーが育てた作品を人質にする保存制限

検討中:

- 初期無料植物数
- 追加植物パックの価格
- 額縁パックの価格
- 月額プランを導入するか
- 広告を入れるかどうか

## モデル推奨設定

Tripoなどで作成するGLBは軽量化を優先する。

目安:

- 512から1Kテクスチャを基本にする
- 植物は必要に応じて1K
- ポリゴン数は20,000以下を目安にする
- スマホ表示前提なので過剰な4Kや高ポリゴンは避ける
